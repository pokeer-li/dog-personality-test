# 犬格测试 · BARK 8

一个零依赖的狗狗专属趣味人格测试。用户完成 12 个狗狗生活现场，得到 8 种专属犬格之一，并查看四字母犬格解释、狗生名场面、养狗说明书和可保存的犬格档案。

## 四字母犬格

- B / C：Bouncy 活力外放 / Calm 稳重克制
- A / I：Affectionate 黏人依赖 / Independent 独立自处
- R / H：Roamer 探索冒险 / Homebody 恋家守门
- K / T：Kibble 食物驱动 / Toy 玩具驱动

## 8 种犬格

金毛·阳光迎宾官、边境牧羊犬·眼神控场王、哈士奇·抽象拆家侠、柯基·短腿小钢炮、柴犬·倔强表情包、贵宾犬·精致戏精、拉布拉多·温柔干饭狗、萨摩耶·微笑泥坑精。

每种犬格都有独立的内联 SVG 场景插画，不依赖外部图片。

## 使用

直接双击 `index.html` 即可打开，无需安装或构建。

本地服务器预览：

```bash
ruby -run -e httpd . -p 8080
```

只有服务器运行期间，`http://localhost:8080` 才能打开；发布到 GitHub Pages 时不需要本地服务器。

## 说明

测试使用常见品种印象和互联网狗梗进行趣味拟人，不是品种鉴定，也不代表犬种与性格存在绝对对应。请以真实观察和专业训犬建议为准。
